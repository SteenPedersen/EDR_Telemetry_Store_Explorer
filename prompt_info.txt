Build a single-page web application called "EDR Telemetry Store Explorer" for querying
and analyzing endpoint detection and response (EDR) telemetry stored in OpenSearch.

VERSION: 26.06.0.103
VERSION FORMAT: YY.MM.minor.build

TECH STACK
----------
- Backend: Python, Flask, Waitress WSGI server (port 5001, host 0.0.0.0)
- Frontend: Bootstrap 5, vanilla JavaScript (no framework), Highlight.js for JSON syntax
- Single template: templates/index.html; single backend: app.py
- All UI state (servers, column sets, filters, widths, timezone, theme) stored in localStorage
- Certificates encrypted with Fernet (AES-128-CBC + HMAC) stored as .enc files in certs/

BACKEND (app.py)
----------------
Endpoints:
  GET  /           Renders index.html with version and any local .pem paths auto-detected
  POST /api/connect   Tests connectivity; returns cluster_name, version, list of indices
  POST /api/search    Proxies OpenSearch _search with mTLS support; returns raw response
  POST /api/save_certs Accepts ca_content/cert_content/key_content PEM strings; encrypts
                       with Fernet and writes to certs/<server-name>/[ca|client|client-key].pem.enc

Certificate/TLS handling:
- _load_fernet(): Load or generate Fernet key at certs/.key (chmod 600)
- _decrypt(path): Decrypt .enc files in memory; read plain .pem files as-is
- _request_factory(data): Returns (http_client, kwargs) configured for the request:
    * skip_hostname=True -> SSLContext with CERT_NONE, assert_hostname=False
    * .enc files present -> SSLContext with CERT_REQUIRED, load cert chain via temp files
      (temp files are deleted immediately after loading; content never persists)
    * Plain .pem -> standard requests cert= and verify= kwargs
- Startup: check requirements.txt and log warnings for missing packages

LAYOUT
------
Single-page Bootstrap layout. Left sidebar (collapsible, ~320px) containing all controls.
Main content area fills the remaining width.

Sidebar sections (top to bottom):
  1. Server selector (dropdown + connect button)
  2. Time filter
  3. Simple / DSL toggle + search input
  4. Filter panel (custom filters + column set filters)
  5. Separator <hr>
  6. Output settings (size, from, tail mode controls)

Navbar (top): App title "EDR Telemetry Store Explorer", version badge, dark/light toggle

Main content tabs:
  Results | Table | Python | PowerShell | (Optimization when not in group mode)

DARK/LIGHT MODE
---------------
Toggle button in navbar. Applies class "dark" to <html>. Full CSS variable override set for
dark theme (backgrounds, text, borders, table stripes). Persisted to localStorage key "theme".

CONNECTION SETTINGS (Settings panel -> Server tab)
--------------------------------------------------
Each server object: { name, url, certPath, keyPath, caPath, skipHostname }
Stored in localStorage key "edr-telemetry-servers".

Two cert input methods:
  (A) "Paste All Certificates": Single textarea accepts full multi-block PEM output from
      `show certificates hxclient` SSH command. Parser extracts CA cert, client cert,
      and private key automatically. On save -> POST /api/save_certs -> files encrypted.
  (B) "Individual .pem file paths" (collapsed by default): Three text inputs for absolute
      paths to ca.pem, client.pem, client-key.pem on the local filesystem.

"Skip hostname verification" checkbox: bypasses IP/hostname validation (use for self-signed
certs on IP addresses).

On connect: POST /api/connect -> displays cluster name, version, index dropdown populated.

SERVER GROUPS
-------------
Groups of servers queried simultaneously; results merged with _serverName field injected.
Stored in localStorage key "edr-server-groups".
When a group is active: Optimization tab is hidden/disabled.
Group editor in Settings panel right column: member list, add/remove, "Use" button.

TIME FILTER
-----------
Preset buttons: All . 1h . 2h . 4h . 8h . 12h . 24h . 7d . 14d . 30d
Custom range: two datetime-local inputs (step: 1s) -- "From" and "To"
Timezone dropdown (21 options): Browser local, UTC, plus named zones across Americas,
Europe, Asia/Pacific. Converts local datetime to UTC ISO for the range query.
Time field: configurable text input (default "time").
Applied as: { range: { [timeField]: { gte: utcFrom, lte: utcTo } } }
Right-click on table time cell: "+-5 min around event" and "+5 min after event" update
the Time Filter sidebar (not the custom filter list) and auto-set timezone to UTC.

SEARCH
------
Simple mode:
  - Text input, placeholder "contains search on all fields"
  - Help text: "The search can be fast if the Time filter is applied or the search
    using filters on specific columns is much faster"
  - Each whitespace-separated token wrapped as *token* wildcard, joined as query_string
DSL mode:
  - Raw JSON textarea with Highlight.js syntax coloring
  - Default template: {"query": {"match_all": {}}}
  - "Format JSON" button
Mode toggle: "Simple" / "DSL (JSON)" buttons.
Search triggered by: "Search [Enter]" button or Enter key anywhere in sidebar.

FILTER SYSTEM
-------------
activeFilters array: each entry { id, type, field, value, logic, op, source }
  source: 'custom' (user-added) or 'set' (from column set predefined filters)

Operators (grouped):
  Text:      contains, equals, not_contains, not_equals
  Range:     gt (>), gte (>=), lt (<), lte (<=), between
  Existence: exists, not_exists

AND/OR logic: clickable badge on each row -- AND (blue) / OR (orange). Toggle on click.
Multi-field: comma-separated field names in one filter -> nested bool.should across those fields.

applyFilters(baseQuery): processes ALL activeFilters regardless of source:
  - posAnd (logic='and', not negative) -> bool.filter
  - posOr  (logic='or',  not negative) -> bool.should (minimum_should_match:1)
  - negFilters (not_equals, not_contains, not_exists) -> bool.must_not

Rendering: two sections in the sidebar filter panel:
  "Custom filters" -- full editable rows (field input, op dropdown, value input,
                      AND/OR toggle button, x delete button)
  "Column set filters" -- partially editable rows: field name and op are static text spans;
                          AND/OR badge is static (no toggle); value field IS an editable
                          <input> wired to updateFilter(id,'value',value); NO delete button.

Hint below filter section header: "Select fields from Event Details by right click"

Right-click on table cell context menu:
  Include (green)   -> adds field=value filter (source='custom'), op='contains';
                       numeric values use op='equals'
  Exclude (red)     -> adds field!=value (not_equals or not_contains)
  Story: Branch     -> filter by parentTraceId
  Story: Chain      -> filter by rootTraceId
  Add to column set -> add this field as a column to a named custom set or new set

updateFilter(id, key, value): mutates activeFilters in memory only.
Filter values are NEVER persisted to localStorage. Custom filters are cleared on page reload.

COLUMN SETS
-----------
8 built-in sets (read-only, cannot be deleted or renamed):
  Default:         time, host, eventType, pFullName, process, cmdLine, targetPath, user,
                   detectionTags
  Process Events:  time, host, eventType, pid, ppid, pFullName, process, cmdLine, user
  Network Events:  time, host, eventType, networkAccess, networkDirection, srcIp, srcPort,
                   dstIp, dstPort, protocol, pFullName, process
  File Events:     time, host, eventType, filePath, faFileType, faSize, faReputation, faMd5,
                   pFullName, process, user
  DNS Events:      time, host, eventType, dnsName, dnsType, network.dnsNames.name,
                   pFullName, process
  Registry Events: time, host, eventType, regPath, regKey, regValueType, regValue,
                   pFullName, process
  ScheduleTask:    time, host, eventType, taskName, taskAction, pFullName, process, user
  Script Events:   time, host, eventType, scriptTimestamp, scriptHash, scriptIntentions,
                   scriptLength, pFullName, process

Custom sets: user-created; stored in localStorage "edr-column-sets". Support duplicate,
rename, delete, drag-to-reorder columns.

Active set stored in localStorage "edr-active-col-set". Picker dropdown in table toolbar
labelled "Column set". Changing the set clears existing set filters, loads new predefined
filters, and triggers a new search.

COL_LIBRARY: 63+ column definitions with id, label, field (dot-path into _source), optional
fmt (display formatter), truncLen, filterField (for right-click), filterFmt.
tblFieldGet(src, field): traverses dot-path on hit._source; field='registry' returns full object.

Special registry column (regPath / "Reg Key Name"):
  field: 'registry' (returns whole registry sub-object)
  fmt: v => [v?.keyName, v?.regKeyName].filter(Boolean).join(' / ')
  filterField: 'registry.keyName'
  filterFmt: v => v?.keyName ?? ''

PREDEFINED FILTERS (_PREDEF_DEFAULTS)
--------------------------------------
Each built-in set has hardcoded default filter templates. On every page load, these always
overwrite the in-memory filter state for built-in set entries (built-in filters are never
read from localStorage; they always reset to code defaults on load). Custom set filters
ARE read from and written to localStorage.

DNS Events:
  OR  eventType equals "DNS Query"
  OR  eventType equals "Network Accessed"
  AND dns.name, network.dnsNames.name contains ''

Default:
  AND host contains ''
  OR  cmdLine contains ''

Process Events:
  AND pFullName contains ''

File Events:
  AND eventType contains 'File'
  OR  fileAttributes.path contains ''
  OR  fileAttributes.md5 contains ''

Network Events:
  OR  eventType contains 'network'
  OR  eventType contains 'dns'
  AND network.dstIp contains ''
  AND network.dstPort equals ''
  AND network.protocol contains ''

Registry Events:
  OR  eventType contains 'reg'
  OR  registry.keyName, registry.regKeyName contains ''
  AND registry.keyValueName contains ''
  AND registry.keyValueName contains ''

ScheduleTask Events:
  AND eventType contains 'schedule'
  AND schedtask.author contains ''
  AND schedtask.name contains ''
  AND schedtask.description contains ''
  AND schedtask.commands contains ''

Script Events:
  AND eventType contains 'script'
  AND scripts.intentions.name contains ''
  AND scripts.intentions.lines contains ''

savePredefFilters(): excludes built-in set entries from localStorage writes.
loadColSetState(): always overwrites built-in entries from _PREDEF_DEFAULTS (no guard).
setActiveSet(id): clears source='set' filters from activeFilters, re-adds from _predefFilters[id].

TABLE VIEW
----------
Toolbar: "Column set" label + set picker dropdown | timezone picker
Timezone picker: UTC or regional zones (same list as time filter). Default UTC.
Stored in localStorage "edr-tbl-tz". Change -> immediate re-render.

All returned results render -- no row cap.
Column headers: click to sort (asc, desc, click again to clear).
Column resize: drag right edge of header. Widths stored in localStorage "edr-col-widths".
Row click: opens event detail side panel (right, max-width 390px).
  Detail panel: all _source fields rendered; nested objects expand; special rendering for
  arrays and cert chains.

Stats bar: "X total . Y ms . showing Z-W"

RESULTS PANEL
-------------
Paginated event cards. Each card: index, _id, _score, source fields table.
"Raw JSON" toggle per card -> Highlight.js JSON view.
Pagination: Prev / Next / page info.

PYTHON TAB
----------
Auto-generated requests snippet reflecting current server URL, index, query, and cert paths.

POWERSHELL TAB
--------------
Auto-generated curl command with --cert, --key, --cacert flags.

LIVE TAIL MODE
--------------
Enforces 1-hour time window. Polls every N seconds (1-3600, default 5).
Prepends new results to Results and Table panels.
Table capped at 1000 rows in tail mode.
Live indicator shows update timestamp and count of new events.

OPTIMIZATION TAB (hidden when server group active)
--------------------------------------------------
Date histogram aggregation (by day).
Top N terms on two configurable field inputs.
Cardinality aggregation on a GUID field.
"Wide" column toggle.

STORY GRAPH
-----------
Directed SVG graph of parent-child trace chains.
Configurable traceId, parentTraceId, parentsTraceId fields.
Event-type colored nodes; node click opens detail panel.

SETTINGS PANEL (three-column layout with resizable dividers)
------------------------------------------------------------
Column 1: Column sets list (built-in read-only + custom editable)
Column 2: Selected set editor -- predefined filters table, column list
Column 3: Server group manager

Predefined filter rows in Settings editor: all fields editable (field, op, logic, value).
Changes to built-in set filters in Settings take effect for the session but do NOT persist --
on next page load the built-in defaults are restored from code.

SECURITY CONSTRAINT
-------------------
PEM certificate content (CA cert, client cert, private key) must NEVER be stored in source
code, documentation, or any committed file. Certificates are accepted only via UI input at
runtime and stored encrypted on disk.
