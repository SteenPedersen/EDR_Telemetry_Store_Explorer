EDR Telemetry Store Explorer

A lightweight web interface for querying and analysing endpoint-detection & response (EDR) telemetry stored in an OpenSearch cluster.

Features
  • Search — build queries with simple field-value filters or raw DSL JSON. Results are shown as collapsible event cards (Results tab) or a sortable, filterable table (Table tab).
  • Table view — click any row to open a full event-detail panel on the right. Right-click any cell or detail field to add include/exclude filters, jump to the Story Graph, or add the field to a custom column set or Group By.
  • Column sets — switch between predefined column sets (Process, Network, File, DNS, Registry, ScheduleTask) or build your own in the Settings tab.
  • Resizable columns — drag the right edge of any column header to resize; widths are remembered across sessions.
  • Code generation — the Python and PowerShell tabs emit ready-to-run SDK snippets that reproduce the current search exactly.
  • Query optimisation — analyses the active query and suggests index mappings, composite aggregations, and date-histogram rollups to improve performance.
  • Group By — aggregate events by one or more fields. Right-click any table or detail-panel cell and choose Add to Group By to send that field to the Group By tab, or type field names manually. Results show event count, unique host count (cardinality), and first / last seen timestamps per bucket. Click a bucket row to apply it as a filter; right-click to include or exclude. Multiple fields are combined with OpenSearch multi_terms. A warning appears when more buckets exist than the chosen Top N.
  • Hunt — paste a block of free-form threat-intelligence text (IOCs, file paths, hashes, domains, IPs, registry keys, mutexes, URLs) or structured CSV (Indicator_type,Data,Note) and run it as a single search across all configured IOC types. Step 1 runs an aggregation-only query and shows the Affected Hosts table with event count, first seen, and last seen per machine. Step 2 loads the matching event cards on demand. Right-click any cell in the Affected Hosts table to add include/exclude filters; right-click First Seen or Last Seen to add a time ≥ / time ≤ filter. Hunts can be saved and reloaded from the Hunt tab toolbar.
  • Story Graph — renders the parent-child trace chain of an event as a directed graph, useful for following attack chains through EDR telemetry.
  • mTLS support — connects over mutual TLS using cert/key/CA files stored locally or pulled from a remote appliance via SSH.
  • Dark / light mode — toggle with the ☀ button in the top bar; preference is persisted across sessions.
Security & Certificate Encryption

Certificates pasted through the UI are encrypted at rest using Fernet symmetric encryption (AES-128-CBC + HMAC-SHA256). A unique encryption key is auto-generated on first run and stored in certs/.key with owner-only read permissions (chmod 600). Certificate files are saved as .enc files inside certs/<server-name>/ — never as readable plain text. Decryption happens in memory only at connect time; any temporary files used during the TLS handshake are deleted immediately after the SSL context is loaded. Servers configured with explicit file paths (not pasted) continue to use those files directly.
